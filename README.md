# 🎯 GoalBuilder

Приложение за записване на всичко, което искате да имате и изградите — организирано по приоритети, категории и статуси, с визуален прогрес, крайни срокове и подзадачи.

## Функционалности

- **Акаунти и автентикация** — регистрация, вход, изход (session cookie + JWT, пароли с bcrypt).
- **База данни** — SQLite (вграден `node:sqlite`), файлове в `data/goals.db`.
- **Цели** — създаване, редактиране, изтриване с заглавие, описание, приоритет, категория, статус и краен срок.
- **Статуси**: Планирано / В процес / Завършено.
- **Приоритети**: Ниска / Средна / Висока / Критична.
- **Крайни срокове** с предупреждение за наближаващи и просрочени цели.
- **Категории** — създаване, редактиране, изтриване с цвят и икона; визуално групиране в списъка и в mind-map карта.
- **Подзадачи** — разбиване на цели на малки стъпки; всяка подзадача има свой статус и допринася към общия прогрес на целта.
- **Визуален прогрес** — прогресивни ленти на карти, статистика и общ напредък.
- **Mind-map изглед** — категориите като клони около център, а целите като възли около категорията.
- **Филтри и търсене** по категория, приоритет, статус и ключови думи.

## Технологии

- Node.js (Express) + SQLite (`node:sqlite`)
- JWT + bcryptjs, HttpOnly cookies
- React 18 + Vite
- SVG mind-map изглед

## За локално стартиране

```bash
npm install
npm run build      # компилира frontend в dist/
npm start          # стартира сървъра на http://localhost:3000
```

За разработка с hot-reload:

```bash
npm run dev
```

Сървърът отваря REST API при `/api/*` и сервира `dist/`.

## Тестване на API

```bash
curl -c cookies.txt -H 'Content-Type: application/json' \
  -d '{"name":"Иван","email":"ivan@example.com","password":"secret123"}' \
  http://localhost:3000/api/auth/register

curl -b cookies.txt http://localhost:3000/api/goals
```

## Основни API маршрути

| Метод | Път | Описание |
| --- | --- | --- |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| POST | `/api/auth/logout` | Изход |
| GET | `/api/auth/me` | Текущ потребител |
| GET/POST | `/api/categories` | Списък / създаване на категории |
| PUT/DELETE | `/api/categories/:id` | Редактиране / изтриване на категория |
| GET/POST | `/api/goals` | Списък / създаване на цели |
| PUT/DELETE | `/api/goals/:id` | Редактиране / изтриване на цел |
| POST | `/api/goals/:goalId/subtasks` | Добавяне на подзадача |
| PUT/DELETE | `/api/goals/:goalId/subtasks/:subtaskId` | Редактиране / изтриване на подзадача |

## Бележка

- `JWT_SECRET` може да се зададе като environment променлива (в production задължително).
- В prod задайте `NODE_ENV=production` за secure cookies.
- Когато подзадачи са създадени, прогресът на целта се изчислява от тях; когато няма, се използва статусът.
